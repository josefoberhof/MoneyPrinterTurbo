# MoneyPrinterTurbo 💸

### Ein All-in-One AI Kurzvideo-Generator

Gib ein Video-**Thema** oder ein **Schlüsselwort** ein, und MoneyPrinterTurbo erstellt automatisch das Skript, sucht passendes Videomaterial, generiert Untertitel sowie Hintergrundmusik und rendert ein fertiges HD-Kurzvideo.

## Funktionen 🎯

### Erstellungsworkflows

- [x] Nutzung über **AI Agent, WebUI, API oder CLI** für schnelle Einzelvideo-Erstellung oder automatisierte Massenproduktion
- [x] Vollautomatisch vom Thema zum Skript, Voiceover, Bildmaterial, Untertiteln, Musik und Schnitt – mit voller Kontrolle über jeden einzelnen Schritt
- [x] Erstellung mehrerer Ausgabevarianten in Batches, Aufgabenhistorie sowie Import/Export von Einstellungen und API-Schlüsseln

### Skripte und Modell-Anbieter

- [x] Generiere oder überarbeite **mehrsprachige Videoskripte** per KI oder verwende ein eigenes vollständiges Skript
- [x] Unterstützung führender Anbieter wie [Kimi / Moonshot AI](https://platform.kimi.ai?track_id=track-f6b0a640d35c41deb03b247242a1058c&aff=moneyprinterturbo), [OpenAI](https://platform.openai.com/api-keys), [Anthropic Claude](https://platform.claude.com/settings/keys), [Google Gemini](https://aistudio.google.com/app/apikey), [DeepSeek](https://platform.deepseek.com/api_keys), [Alibaba Cloud Qwen](https://qwen.ai/apiplatform), [Microsoft Azure OpenAI](https://portal.azure.com/#view/Microsoft_Azure_ProjectOxford/CognitiveServicesHub/~/OpenAI), [ByteDance VolcEngine Ark](https://console.volcengine.com/ark), [xAI Grok](https://console.x.ai/), [MiniMax](https://platform.minimax.io/) und [Xiaomi MiMo](https://platform.xiaomimimo.com/docs/zh-CN/quick-start/first-api-call)
- [x] Anbindung über [Shengsuan Cloud](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK), [APIMart](https://go.apimart.ai/gh-moneyprinterturbo), [Cloudflare AI Gateway](https://dash.cloudflare.com/), [Alibaba ModelScope](https://modelscope.cn/docs/model-service/API-Inference/intro), [AIHubMix](https://aihubmix.com/), [AIML API](https://aimlapi.com/app/keys), [EvoLink](https://evolink.ai/dashboard/keys), [OpenRouter](https://openrouter.ai/settings/keys), [Ollama](https://ollama.com/), [OneAPI](https://github.com/songquanpeng/one-api), [LiteLLM](https://docs.litellm.ai/docs/providers), [Groq](https://console.groq.com/keys), [Pollinations AI](https://enter.pollinations.ai/) und weitere kompatible Gateways/lokale Runtimes

### Video- und Bildmaterial

- [x] Lade **lokale Bilder und Videos** hoch oder nutze HD-Stockmaterial von [Pexels (kostenlos)](https://www.pexels.com/api/), [Pixabay (kostenlos)](https://pixabay.com/api/docs/) und [Coverr](https://coverr.co/developers?ctx=header_navigation)
- [x] Generiere `768P` oder `2K` Quellmaterial mit [Metaso MiniMax H3](https://metaso.cn/minimax-h3/?s=MPT) (4–15 Sekunden Clips in `9:16`, `16:9` oder `1:1`)
- [x] Erstelle KI-Videoclips mit [Shengsuan Cloud AI Video](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK) und kombiniere sie mit Voiceover und Untertiteln
- [x] Nutzung nativer [Volcano Engine Ark Seedance](https://console.volcengine.com/ark/region:ark+cn-beijing/apikey) Integrationen für zusammenhängende Visualisierungen
- [x] Generiere Videos aus Skript-Keywords via [WaveSpeed AI](https://wavespeed.ai)
- [x] Greife über [OFox](https://ofox.ai) auf Seedance, Wan und andere Text-to-Video-Modelle mit einem einzigen API-Schlüssel zu
- [x] Verbinde OpenAI-kompatible Text-to-Image-Dienste und verwandle generierte Bilder in animierte Videoclips
- [x] Passe Clipdauer, Bildeinpassung und Materialreihenfolge individuell an

### Voiceover, Untertitel und Hintergrundmusik

- [x] Wähle automatische Sprachausgabe, hochgeladenes Audio oder Stummmodus inkl. Vorschau
- [x] Nutze **Edge TTS (kostenlos, kein API-Schlüssel nötig)**, Azure Speech, SiliconFlow, Google Gemini, Xiaomi MiMo, MiniMax, ElevenLabs, Chatterbox, Kokoro, Fish Audio, ModelBest VoxCPM u. v. m.
- [x] Erstelle Untertitel und konfiguriere Schriftart, Position, Farbe, Größe, Kontur und Hintergrundstil
- [x] Nutze zufällige, lokale oder KI-generierte Hintergrundmusik mit unabhängiger Lautstärkeregelung

### Ausgabe und Veröffentlichung

- [x] Exportiere Hochformat `9:16 (1080×1920)`, Querformat `16:9 (1920×1080)` oder Quadrat `1:1 (1080×1080)` Videos
- [x] Veröffentliche fertige Videos direkt auf **TikTok, Instagram und YouTube Shorts**

## Systemanforderungen 📦

- Empfohlene Betriebssysteme: Windows 10+, macOS 11+ oder eine gängige Linux-Distribution
- Lokale Installation erfordert Python 3.11 oder neuer (Python 3.11 wird empfohlen)
- Eine GPU ist nicht zwingend erforderlich, wird aber für schnellere lokale Transkription, Videoverarbeitung und Batch-Generierung empfohlen

| Komponente | Minimum      | Empfohlen    | Optimal    |
| ---------- | ------------ | ------------ | ---------- |
| CPU        | 4 Kerne      | 6 bis 8 Kerne| 8+ Kerne   |
| RAM        | 4 GB         | 8 GB         | 16+ GB     |
| GPU        | Nicht nötig  | 4+ GB VRAM   | 8+ GB VRAM |

## Schnellstart 🚀

### Empfohlene Wege

- **Ohne manuelle Einrichtung:** Generiere Videos direkt mit einem AI Agent.
- **Windows-Nutzer:** Nutze das Ein-Klick-Paket für den schnellsten lokalen Test.
- **macOS / Linux-Nutzer:** Nutze `uv` für die primäre lokale Einrichtung.
- **Isolierte Laufzeitumgebung:** Nutze die Docker-Bereitstellung.

### Videos mit einem AI Agent erstellen

Wenn dein AI Agent Skill-Dokumente lesen und ein Terminal bedienen kann, sende ihm folgenden Prompt (unterstützt macOS und Windows):

```text

Create a video with the topic "How AI is changing everyday life."
